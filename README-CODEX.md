# Assets Fullness Lab para Remotion / Codex

Copia esta carpeta dentro de la raíz del proyecto:

```txt
/public/assets/fullness/
  bolsa-cerrada.png
  fondo-oscuro.png
  salmon.png
  kale.png
  betarraga.png
  camote.png
  quinoa.png
  esparragos.png
  plato-final.png
```

También incluí `logo-oficial-blanco.png` por si luego quieres usarlo, pero para la secuencia actual dejamos la bolsa sin logo.

Prompt sugerido para Codex:

```txt
Usa los assets de /public/assets/fullness para crear una animación premium en Remotion.
Empieza con bolsa-cerrada.png al centro sobre fondo-oscuro.png.
Luego agrega vapor, partículas doradas, apertura de bolsa simulada con máscaras y movimiento.
Anima salmon.png, kale.png, betarraga.png, camote.png, quinoa.png y esparragos.png saliendo de la bolsa en cámara lenta y cayendo hacia un plato.
Termina con plato-final.png y líneas nutricionales finas doradas.
No inventes logos y no pongas texto sobre la bolsa.
```

Nota: los ingredientes individuales son recortes base extraídos de la imagen actual. Sirven para prueba y animación inicial. Si queremos un resultado final ultra premium, conviene reemplazarlos por PNGs aislados generados uno por uno.
