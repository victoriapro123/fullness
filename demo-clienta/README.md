# Demo Fullness

Esta carpeta documenta las decisiones tomadas para la demo de la web Fullness, siguiendo las instrucciones entregadas por la clienta durante el proceso.

## Objetivo

Crear una pagina web para Fullness, una marca de comida real lista para servir, con una estetica elegante, natural y llamativa.

La propuesta comunica:

- Alimentacion antiinflamatoria.
- Ingredientes reales.
- Comida lista para servir en bolsas al vacio.
- Comunidad y acceso para miembros.
- Carrito funcional para agregar productos.

## Estado actual

La demo ya incluye una portada con video principal, direccion visual Fullness Lab, navegacion, secciones de filosofia y nutricion funcional, franja de calentado, productos, carrito, acceso a miembros y una animacion al agregar productos al carrito.

La portada se actualizo para levantar las cuatro patas definidas por la clienta:

- Practico: lo bueno hecho simple.
- Rico: food porn y placer gastronomico.
- Antiinflamatorio: nutrientes, vitaminas, minerales y combinaciones funcionales.
- Premium: paleta oscura, dorados opacos, burdeo betarraga y lenguaje editorial.

El proyecto esta preparado para desplegarse en Vercel desde GitHub.
